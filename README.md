# Zara-Dashboard
I created this dataset to showcase a Power BI visualization project based on the publicly available Zara dataset from Kaggle. The dashboards provide insights into:

Top-performing products via Sale volume and Revenue

Sales volume vs. pricing relationships

The effect of product placement (front-of-store, aisle, end-cap)

Promotional impact on sales volume

The goal of this analysis is to demonstrate how raw retail data can be transformed into actionable insights using data visualization and business intelligence tools.
